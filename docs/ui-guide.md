# Terminator 界面与交互指南

> 适用版本：v0.8.11 及之后的界面重构版本。本文说明窗口结构、信息层级、状态含义与常用操作路径；功能清单见 [README](../README.md)。

## 设计原则

界面沿用「Quiet Precision」的仪器化语言，而不是通用后台面板：

- **单一强调色**：选中态、主操作、焦点环只使用一个强调色，其余状态用语义色（成功 / 警告 / 错误 / 中性）。
- **发丝线分层**：用 1px 半透明分隔线与表面明度差建立层级，不依赖大圆角卡片和重阴影。
- **等宽微标签**：分组标题、状态条、端点、分组胶囊使用小号等宽字体，让信息像仪表读数而不是段落文字。
- **克制动效**：悬停、切换只做短时颜色与透明度过渡；系统开启「减少动效」时自动降级。
- **动作就近**：与当前会话相关的入口（新建标签、文件面板、广播、状态）放在使用它们的地方，不堆进设置页。

## 界面总览

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 品牌区（与侧栏同宽）      标签栏 + 新建标签        操作区 │ 窗口控制     │
├──────────────┬───────────────────────────────────────────────────────────┤
│ 工作区        │                                                           │
│  主机         │                                                           │
│  密钥         │                    页面内容 / 终端会话                     │
│  端口转发     │                                                           │
│ 工具          │                                                           │
│  快速连接     │                                                           │
│ ...           │                                                           │
│ 状态卡        ├───────────────────────────────────────────────────────────┤
│               │ 连接态 │ 端点 │ 延迟 │ 广播 │ 传输      SSH/LOCAL │ UTF-8 │
└──────────────┴───────────────────────────────────────────────────────────┘
```

窗口分为四层：标题栏（含标签栏）、左侧导航栏、主内容区、终端底部状态条。侧栏宽度与标题栏左侧品牌区对齐，窗口缩放时保持一条垂直基准线。

## 标题栏与标签栏

标题栏高 40px（随显示密度缩放），整条可拖动窗口；其中的按钮与标签均为 `no-drag` 区域。

| 区域 | 组成 | 说明 |
|---|---|---|
| 左侧品牌区 | 应用图标 + Terminator、侧栏折叠按钮 | 终端视图下折叠侧栏后，品牌区收缩为 48px 的图标条 |
| 中部标签栏 | 会话标签、标签尾部 `+` | 标签可横向滚动；激活标签自动滚入视口，两端有渐隐提示 |
| 右侧操作区 | 资源面板、分屏、广播、文件面板、本地终端、窗口控制 | 按「状态 → 布局 → 工具 → 窗口」分组，组间用发丝线分隔 |

### 标签交互

| 操作 | 结果 |
|---|---|
| 单击 | 切换到该会话 |
| 双击标题 | 原地重命名 |
| 拖动 | 调整标签顺序 |
| 中键单击 | 关闭标签（开启「关闭标签页前确认」时会先确认） |
| 右键 | 打开标签菜单：重命名、复制会话、重连、复制 SSH 命令、标签颜色、关闭其他/右侧/当前 |

标签左侧状态点表示连接状态；后台会话有新输出时显示脉冲圆点，命令结束且标签不在前台时显示绿色完成勾。标签颜色需在「设置 → 终端 → 标签页自定义颜色」中开启。

### 新建标签菜单

点击标签末尾的 `+`，或使用命令面板中的「新建标签」动作：

- **本地终端**：不经过 SSH，直接打开本机 PowerShell。
- **快速连接**：输入地址与凭据连接，不写入主机列表。
- **浏览主机**：切换到主机页，从已保存的主机中选择。

## 侧边栏

侧栏由逻辑分组与底部状态卡组成：

- **工作区**：主机、密钥、端口转发。
- **工具**：快速连接（不保存主机的一次性连接）。
- **底部**：检查更新（仅在有可用更新时出现）、设置、保险库与同步状态卡。

状态卡副标题按优先级显示：

1. 有未解决的同步冲突时显示「N 个冲突待处理」，点击进入「设置 → 同步」。
2. 否则显示同步状态：本地模式 / 同步中… / 已同步 / 同步异常。
3. 圆点颜色随状态变化：灰色空闲、蓝色同步中、绿色成功、红色失败。

终端视图下可以用标题栏左侧的按钮折叠侧栏；设置页会暂时收起主侧栏，改用设置页自己的分类导航（左上角返回按钮回到进入设置前的页面）；其余页面始终展开侧栏。

## 工作区

### 空状态

没有任何会话时，工作区显示引导页而不是空白画布，提供三个入口：

- **快速连接**（主按钮）
- **浏览主机**
- **本地终端**

底部提示 `Ctrl+Shift+P` 可呼出命令面板。

### 底部状态条

状态条只在存在会话时出现，集中展示当前会话事实：

| 片段 | 含义 |
|---|---|
| 连接状态 | 已连接 / 连接中 / 已断开，颜色对应成功 / 警告 / 错误 |
| 端点 | `user@host:port`；本地终端显示名称；过长时截断，悬停查看完整值 |
| 延迟 | 仅已连接的 SSH 会话显示，每 10 秒采样一次；失败显示占位符 |
| 广播 | 广播模式开启时以警告色显示 |
| 传输 | 当前会话进行中的 SFTP 传输数量，点击切换文件面板 |
| 右侧属性 | `SSH` / `LOCAL` 与 `UTF-8` |

### 终端浮层按钮

终端列右下角有两个浮动按钮：

- **草稿栏**（`Ctrl+Shift+U`）：多行编辑后再发送。
- **代码片段**：按分组执行片段。

按钮锚定在终端列内部，文件面板展开时不会覆盖 SFTP 列表；草稿栏打开时按钮自动上移。

### 分屏

- `Ctrl+Shift+D`：左右分屏。
- `Ctrl+Shift+E`：上下分屏。
- 拖动中间分隔条调整比例，每侧最小 18%。
- 标题栏右侧出现「取消分屏」按钮；分屏关系按标签保留，切走再切回即恢复。

## 页面

### 主机

```text
[ 搜索框（匹配名称/地址/用户名/分组）              立即连接 ]
[ 新建主机 ⌄ ] [ 本地终端 ]

最近连接   [主机 A] [主机 B] ...
分组       [分组胶囊 + 数量] ...

主机       [ 卡片网格 ]
```

- **搜索框**：输入即过滤；选中卡片后右侧「立即连接」可用。
- **新建主机**：主按钮打开新建面板；右侧下拉菜单提供导入主机、导出主机、从 `~/.ssh/config` 导入。
- **最近连接**：最多 6 台，点击直接发起连接；记录只存本地，不参与同步。
- **分组胶囊**：点击启用筛选，再次点击取消；胶囊上的数字是该分组主机数量。
- **主机卡片**：名称 + 端点 + 右侧分组标签。单击打开详情面板，双击直接连接，右键弹出连接 / 编辑 / 删除菜单。
- **详情面板**：地址、端口、认证方式、跳板机、代理、Agent 转发、登录后执行命令；底部提供「立即连接」与「保存主机」。

### 密钥

- 工具栏只有「新建密钥」与搜索，保持与主机页相同的紧凑结构。
- 卡片显示名称与推断出的密钥类型（Ed25519 / RSA / ECDSA 等）。
- 单击卡片打开右侧编辑面板；右键可编辑或删除。
- 保存后立即应用于引用该密钥的主机，无需重连其他主机。

### 端口转发

- 列表按「转发规则」分区，行内展示类型图标、本地地址 → 远程地址、来源会话、运行状态。
- 「添加转发」要求至少存在一个已连接的非本地 SSH 会话；没有会话时按钮禁用并给出提示。
- 新建面板中，转发类型使用分段控件：本地转发 / 远程转发，下方即时说明流量方向。
- 删除采用乐观更新：先移除条目再调用后端，失败时自动恢复条目。

### 设置

设置页占用完整内容区：主侧栏隐藏，标题栏品牌区与设置分类导航同宽；窄窗口下设置行的标签与控件自动改为上下堆叠，分段控件可整行换行。

| 分组 | 分类 | 主要选项 |
|---|---|---|
| 偏好设置 | 外观 | 深色/浅色主题、外观皮肤、语言、强调色、密度、终端配色联动 |
| 偏好设置 | 终端 | 字体、字号、行高、光标样式与闪烁、滚动缓冲、关闭确认、选中即复制、关键词高亮、广播、标签颜色、多行粘贴保护、断线自动重连、SFTP 跟随目录、恢复上次工作区、命令完成通知、快照、会话日志 |
| 偏好设置 | 快捷键 | 可配置动作 + 固定快捷键说明；支持录制、冲突检测、单项/全部恢复默认 |
| 数据与安全 | 同步 | 账户信息、服务器同步、WebDAV、冲突面板 |
| 数据与安全 | 安全 | 锁定保险库、自动锁屏、清除保险库、已知主机、加密备份 |
| 数据与安全 | 系统 | 开机自启、关闭到托盘、清空最近连接 |
| — | 关于 | 检查更新、下载并校验安装包、打开发布页 |

## 浮层与面板

| 组件 | 行为 |
|---|---|
| 右侧滑出面板 | 主机 / 密钥 / 端口转发的新建与编辑；头部标题 + 端点副标题，底部固定操作区 |
| 命令面板 | `Ctrl+Shift+P`；主机、片段、动作分组；方向键选择、Enter 执行、Esc 关闭 |
| 快速连接 | 侧栏或空状态入口；输入地址与凭据后直接开新标签 |
| 确认弹窗 | 删除主机 / 密钥、覆盖下载、关闭已连接标签、清除保险库等破坏性操作 |
| Toast | 右下角，位于状态条之上；成功与失败均不遮挡状态信息 |

## 状态与颜色

| 视觉 | 含义 |
|---|---|
| 绿色圆点 / 绿色文字 | SSH 已连接、转发活跃、同步成功 |
| 黄色 / 警告色 | 连接中、广播模式开启、延迟较高 |
| 蓝色 | 同步进行中、信息提示 |
| 红色 / 危险色 | 已断开、同步失败、传输失败、冲突横幅 |
| 灰色 | 本地模式、空闲、未知、无会话 |
| 标签脉冲圆点 | 非当前标签有新的终端输出 |
| 标签绿色勾 | 非当前标签的命令已结束 |

## 快捷键

可在「设置 → 快捷键」中修改带 * 的组合；固定快捷键不可改。

| 快捷键 | 动作 |
|---|---|
| `Ctrl+Shift+P` * | 命令面板 |
| `Ctrl+F` * | 终端内搜索 |
| `Ctrl+Shift+D` * | 左右分屏 |
| `Ctrl+Shift+E` * | 上下分屏 |
| `Ctrl+Shift+U` * | 命令草稿栏 |
| `Ctrl+Shift+C` | 复制终端选中文本 |
| `Ctrl+Shift+V` | 粘贴到终端 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 循环切换标签 |
| `Ctrl+PageUp` / `Ctrl+PageDown` | 向左 / 向右切换标签 |
| `Ctrl+滚轮` | 调整终端字号 |
| `Esc` | 关闭终端搜索 / 关闭浮层 |
| `Enter` | 激活键盘聚焦的标签 |

## 个性化

- **主题**：深色 / 浅色。
- **外观皮肤**：默认、HUD 战术（恒暗，偏科技读数）、编辑纸感（恒亮，偏纸面排版）。皮肤会覆盖主题的明暗语义。
- **强调色**：默认、天蓝、翡翠绿、紫罗兰、琥珀橙、玫瑰红、青色。
- **密度**：紧凑 / 标准 / 宽松，统一缩放标题栏、标签、侧栏、行高与状态条。
- 以上偏好全部持久化，重启后自动恢复。

## 常见任务路径

1. **首次启动**：创建本地保险库或连接云端账户 → 进入工作区。
2. **连接一台主机**：主机页双击卡片；或按 `Ctrl+Shift+P` 搜索主机；或使用快速连接。
3. **打开本地终端**：标签栏 `+` → 本地终端；或标题栏右侧的终端图标。
4. **打开 SFTP**：标题栏右侧文件夹按钮；或点击状态条的传输计数。
5. **广播命令**：先在设置中开启广播功能，再在标题栏点亮广播按钮，之后输入会发送到所有活动会话。
6. **查看会话日志**：设置 → 终端 → 会话日志，开启记录并设置保留期；在同一卡片的查看器中检索、预览、导出。
7. **处理同步冲突**：点击侧栏状态卡或顶部横幅 → 设置 → 同步 → 逐条选择保留本机 / 保留云端。
8. **锁定保险库**：设置 → 安全 → 锁定保险库；或命令面板中的「锁定保险库」。锁定会清空内存凭据并断开全部会话。

## 可访问性与细节

- 所有可交互元素都有 `focus-visible` 焦点环，Tab 可遍历，Enter 可激活。
- 悬停才出现的行内操作在键盘聚焦时同样可见，且隐藏时不接收指针事件。
- 长文本统一截断并通过 `title` 提供完整值；状态条端点单独限制宽度，避免挤压右侧属性。
- 尊重系统「减少动效」设置：滚动与过渡改为即时完成。
- 颜色之外始终配有文字或图标（连接状态、同步状态、传输状态），不单靠颜色传达信息。

## 实现备注（开发者）

- 设计令牌集中在 `frontend/src/assets/main.css`：表面层级、前景色、发丝线、密度、动效与状态条高度。
- 壳层组件：`layout/Sidebar.tsx`、`layout/TitleBar.tsx`、`layout/StatusBar.tsx`、`terminal/TerminalStack.tsx`。
- 页面与面板：`views/HostsPage.tsx`、`views/KeysPage.tsx`、`views/PortForwardingPage.tsx`、`views/SettingsPage.tsx`、`ui/slide-panel.tsx`。
- 新增界面文案需同时补齐 `frontend/public/locales/zh` 与 `en`，并运行 `npm run check:i18n`。
- 提交前至少运行：`npx tsc --noEmit -p tsconfig.json`、`npm run check:i18n`、`npm run build`。
